# Changelog

Notable changes to `aisdk/transport`. Release notes are also published at https://github.com/phpaisdk/transport/releases.

## v0.11.1 — 2026-11-11

- The `aisdk/transport` test suite now supports Pest 3, 4, and 5; Pest 5 requires PHP 8.4.

## v0.11.0 — 2026-10-31

- Requires `aisdk/core ^0.11.0`. Upgrade SDK packages together; no other changes in this package.

## v0.10.0 — 2026-10-29

### What's new

- WebSocket close failures are preserved so callers can observe them.

### Compatibility

- Requires `aisdk/core ^0.10.0`. Upgrade SDK packages together.

## Earlier releases

See the [GitHub releases](https://github.com/phpaisdk/transport/releases) for versions before 0.10.0.
